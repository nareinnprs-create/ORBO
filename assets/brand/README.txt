ORBO DIYA BRANDING KIT
Version: 1.0 — working production starter pack

BRAND HIERARCHY
OPRAIZ = parent company / endorsed brand
ORBO = primary product name
Diya = secondary name within the product name
Approved descriptors:
- Your Personal AI Companion.
- Think. Remember. Plan. Act.

IDENTITY DIRECTION
Premium, precise, intelligent, calm, cinematic technology.
Core symbol: iridescent orbital ring. Do not replace it with a lamp, flame, or unrelated symbol.
Use the orbital ring consistently; do not stretch, rotate, recolour, or add effects to the supplied artwork in production.

PALETTE
Obsidian #080F14 — primary dark background
Deep Teal #006E7A — UI / supporting colour
Rich Teal #00C2D4 — highlight
Cinematic Blue #2F6BFF — gradient
Violet #8A3FFC — accent
Copper #F6C284 — warm accent
Ivory #FFF9F1 — light background
Slate #667782 — secondary text

TYPOGRAPHY
Primary: Montserrat (wordmark/headlines). Use a licensed font file in production.
Secondary: Inter (UI/body). Use a licensed font file in production.
Fallbacks in SVGs are system sans-serif fonts; outlined final wordmarks are recommended before release.

LOGO USAGE
- Primary logo: hero pages, brand decks, launch visuals.
- Horizontal logo: nav bars, email signatures, compact layouts.
- Stacked logo: centered/social/packaging applications.
- Icon-only: app icons, favicon, avatars.
- Monochrome: single-colour printing, embossing, engraving.
- Clear space: keep at least 1x the visible ring stroke width around all sides.
- Digital minimums: icon-only 24 px; wordmark lockup 160 px wide recommended.
- Print minimums: icon-only 8 mm; wordmark lockup 30 mm wide recommended.
- Do not stretch, rotate, recolour, outline, add glows/shadows, or place on busy backgrounds.
- Keep contrast strong and retain generous whitespace.

APP ICONS
Exported PNG sizes: 1024, 512, 256, 64, 32 and 16 px. Platform-specific safe areas, masking, and store requirements must be validated in each target platform before publishing.

IMPORTANT PRODUCTION NOTE
These vector logos are clean reconstructed starter masters based on the visual direction shown in the conversation, not traced source vectors of an independently supplied approved logo file. The gradient and ring geometry are a consistent approximation. Before commercial release, compare against the authoritative approved logo and replace the SVG paths if exact geometric fidelity is required. HEX values in this kit are standardized working values and should be treated as the proposed production palette until formally signed off.
