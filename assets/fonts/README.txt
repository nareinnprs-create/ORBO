ORBO DIYA — TYPOGRAPHY FILES

Primary typeface: Montserrat
Use: wordmark/headlines/campaign titles
Included weights: Regular, Medium, SemiBold, Bold (OTF)

Secondary typeface: Inter
Use: product UI/body text/navigation/forms
Included weights: Regular, Medium, SemiBold, Bold (OTF)

Both typefaces are distributed under the SIL Open Font License 1.1. Retain their license notices when redistributing font files. Before shipping fonts inside a commercial application or a redistributed asset pack, verify the current official license text and reserved-name provisions at the upstream project pages.

Official upstream sources:
Montserrat: https://github.com/google/fonts/tree/main/ofl/montserrat
Inter: https://github.com/google/fonts/tree/main/ofl/inter

These are static OTF weights rather than variable-font files. Use the weight that matches the design system; do not synthetically embolden Regular when a real Bold file is available.
